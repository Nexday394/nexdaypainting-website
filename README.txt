NEXDAY PAINTING WEBSITE
=======================

This is a static one-page website ready for Cloudflare Pages.

UPLOAD TO CLOUDFLARE PAGES
1. Unzip this package.
2. Upload the contents of the nexday-painting-website folder using Direct Upload.
3. Connect the domain nexdaypainting.com.au in Cloudflare Pages.
4. Ensure both the root domain and www version redirect to your preferred domain.

IMPORTANT
- Quote, phone, email, Instagram, Facebook, Google profile and Google review links are already connected.
- The canonical domain is set to https://nexdaypainting.com.au/
- If the preferred live domain is www.nexdaypainting.com.au, update the canonical URL, sitemap and structured data in index.html.
- Review the service areas and wording before publishing.
